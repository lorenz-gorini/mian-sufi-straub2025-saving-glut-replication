# Authors' February 2021 Data

This directory contains no copied datasets. `authors_data` is a relative
symlink to `../../../MSS2021Febreplicationkit/data`, the immutable vendor
snapshot.

Use the symlink only for convenient navigation. Code and provenance records
should cite the canonical `MSS2021Febreplicationkit/data/` path, and nothing may
write through the link. See
[`../../../docs/data/author-kit-data-map.md`](../../../docs/data/author-kit-data-map.md)
for the selective folder inventory, hydration order, and storage policy.
