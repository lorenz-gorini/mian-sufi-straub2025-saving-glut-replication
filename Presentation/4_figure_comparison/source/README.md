# Editable presentation source

This folder preserves the durable authoring inputs for the Figure Comparison
deck. The final deliverable remains `../presentation.pptx`.

## Contents

- `build_presentation.mjs`: editable Artifact Tool source for the current
  Figure 6 additions and the associated deck-wide labels and numbering;
- `template-starter.pptx`: the 17-slide template-following base from which the
  build script produces the maintained deck;
- `template-frame-map.json`: maps every output slide to its inherited source
  slide and records permitted edits;
- `template-audit.txt` and `deviation-log.txt`: template structure and
  intentional departures;
- `source-notes.txt`: source provenance assembled during authoring; and
- `rebuild_presentation.zsh`: reproducible build entry point.

The reusable cropped paper exhibit is stored in
`../assets/paper_figure6_no_caption.png`. The Figure 6 raster overlay and other
empirical charts are generated by the Python scripts listed in `../README.md`;
rebuild those charts before rebuilding the deck if their underlying results
change.

## Rebuild

From the project root, run:

```zsh
Presentation/4_figure_comparison/source/rebuild_presentation.zsh
```

The command initializes an isolated Artifact Tool workspace under
`/private/tmp`, writes the deck to `../presentation.pptx`, and retains renders,
layout exports, and inspection files in the printed temporary path for QA. Pass
an explicit output path as the first argument to test a build without replacing
the maintained deck.

If the installed presentation skill moves, set `PRESENTATIONS_SKILL_DIR` to its
current absolute directory before running the command.

Do not commit `node_modules`, rendered slides, layout dumps, inspection files,
or temporary Python dependencies. They are regenerated for each build and do
not contain authoring decisions.
