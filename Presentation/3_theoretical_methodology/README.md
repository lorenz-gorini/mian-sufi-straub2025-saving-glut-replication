# Theoretical methodology presentation

This folder is an independent presentation module for the theoretical core of
Mian, Straub, and Sufi (2025), Sections 2.1--2.2. It deliberately excludes the
data architecture, empirical reconstruction, and figure-by-figure results,
which belong in separate numbered presentation folders.

## Contents

- `presentation.pptx`: canonical editable 16-slide deliverable using the
  project-wide PowerPoint hierarchy;
- `presentation_short.pptx`: condensed seven-slide companion for combining
  the method with data and empirical-result modules;
- `presentation.pptx.inspect.ndjson`: generated structural inspection record;
- `presentation_short.pptx.inspect.ndjson`: structural inspection record for
  the condensed deck;
- `presentation.tex`: historical 16:9 Beamer source;
- `presentation.pdf`: historical compiled Beamer artifact;
- `assets/leontief-network-cover.png`: conceptual ImageGen cover artwork;
- `assets/pptx-veil-chain.dot` and `assets/pptx-four-sector.dot`: exact source
  graphs embedded in the current PowerPoint;
- `../math-assets/equations.tex`: shared LaTeX source for every substantive
  equation embedded in the PowerPoints;
- `generated/unveiling_values.tex`: generated numerical macros for the exact
  four-sector example.

The Beamer quantitative diagrams are TikZ. The PowerPoints embed raster exports
of the two exact Graphviz sources listed above and vector SVG exports from the
shared LaTeX equation source. Titles, labels, panels, bars, and explanatory
text remain editable PowerPoint objects; equations remain reproducible and
scientifically typeset rather than approximated as editable Unicode text.

The PowerPoint is now the delivery and maintenance target. The Beamer source is
retained for provenance and should not be treated as visually synchronized.

## Scope and source boundary

The deck explains:

1. issuer-to-holder orientation and direct ownership shares;
2. Equation (4), which constructs the direct ownership matrix;
3. the block matrices `B` and `Q` and the path expansion;
4. Equation (1), the Leontief-style solve;
5. a complete four-sector network and its path reconciliation;
6. Equations (2)--(3), which reconnect ownership to net worth and primary
   assets;
7. the readable Python implementation and its relation to the authors' older
   seven-round Stata procedure.

The deck now distinguishes two operations that were previously conflated.
Figure 1 counts direct household claims on intermediary issuers after the
direct-dollar network is built, before the Leontief solve. The 2021
seven-stage procedure is also not presented as
\(\sum_{r=0}^{7}Q_t^rB_t\): its instruments, adjustments, and residual rules
change across stages. It shares proportional allocation logic with the revised
method, but equivalence requires the same completed direct matrix.

## Rebuilding

Future PowerPoint edits must follow `../README.md`: one-line takeaway title,
one dominant visual or equation, subordinate explanation, a separate
`WHY IT MATTERS` band, and a source rail. Render every slide after edits.
Update `../math-assets/equations.tex` whenever an equation changes, regenerate
the SVGs, and preserve each SVG's native aspect ratio when embedding it.

Regenerate the embedded graph assets, if needed, with:

```sh
dot -Tpng assets/pptx-veil-chain.dot -o /tmp/pptx-veil-chain.png
dot -Kneato -Tpng assets/pptx-four-sector.dot -o /tmp/pptx-four-sector.png
```

To rebuild the historical Beamer artifact:

From this folder:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error presentation.tex
```

The numerical macros are generated by
`Code/scripts/build_unveiling_teaching_assets.py`. The local copy is kept here
so this deck cannot be overwritten by, or acquire hidden dependencies on, the
other presentations.
